# Labex_Machina
Questo repository nasce per documentare le sperimentazioni hardware e software di Labex Machina, un progetto didattico che avvicina gli studenti di design alla progettazione di oggetti dinamici attraverso l’esplorazione, la costruzione e la verifica di prototipi funzionanti.
